# Tech-Gear

Tech-Gear is an early web development learning project created while practicing HTML and CSS together with a teacher and classmates.

The project was part of my first hands-on coding experiences, where we learned how to structure a webpage, apply styling, and build a website step by step. It represents an important part of my early journey into front-end web development.

## Tech Stack

- **HTML5:** Website structure and content
- **CSS3:** Styling and layout design

## Getting Started

### Prerequisites

- A modern web browser
- A code editor, such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/Tech-gear.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Tech-gear
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Project Structure

```text
Tech-gear/

```
